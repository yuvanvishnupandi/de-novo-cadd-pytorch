🎯 1. Project Overview

EUREKA is an AI-powered drug discovery pipeline that generates novel chemical molecules and rigorously filters them through multiple AI-driven criteria to identify safe, effective drug candidates.

Principle Description
Generative AI Uses a Deep Learning LSTM neural network to create novel molecules from scratch (De Novo generation)
Machine Learning Uses Random Forest classifiers to grade each molecule for bioactivity and toxicity
No Agentic AI The pipeline is strictly deterministic — AI does not make autonomous decisions about the workflow
Prompt Engineering Temperature Scaling controls how creative vs. conservative the GenAI's molecular output is

In plain English: the AI invents new molecules → checks if they have drug-like chemical properties → checks if they would actually cure the target disease → checks if they are poisonous → simulates 3D physical binding to the disease protein → outputs only the winners.

🔄 4. How The Pipeline Actually Runs

When the FastAPI server is running and the /api/discover endpoint is called from the React frontend (or Swagger UI):

React Frontend → FastAPI Server POST /api/discover {target, n_molecules, temperature}
FastAPI Server → Pipeline Manager run_pipeline(n=10)
Pipeline Manager → PyTorch LSTM Generate 10 novel SMILES molecules
    ⚠️ If trained weights missing → uses fallback bank of 15 known FDA drugs
Pipeline Manager → PubChem API For each molecule: get MW, LogP, HBD, HBA
Pipeline Manager → Lipinski Check Rule of 5 validation (≤1 violation allowed)
Pipeline Manager → Bioactivity RF predict_bioactivity(features) → "active" / "inactive"
Pipeline Manager → Toxicity RF predict_toxicity(features) → toxic (1) / safe (0)
Pipeline Manager → FastAPI Server Return approved_molecules[] + save to CSV
FastAPI Server → React Frontend JSON: {status, total_generated, total_approved, discovered_molecules}

Importantly, this project uses strictly Generative AI and Machine Learning. There is no Agentic AI — the pipeline is fully deterministic and does not make autonomous decisions. Every step follows a fixed, rule-based sequence."

📍 Phase 3 — Explain the AI Models (3 min)

What to show: Open ai_models/genai_model.py and show the LSTM class.

Step 3a — Explain the GenAI LSTM (Deep Learning / NLP concept):

"This is our Generative AI model — a character-level LSTM (Long Short-Term Memory) Neural Network. LSTM is a foundational architecture from NLP (Natural Language Processing).

Just like GPT learns the grammar of English to generate text, our LSTM learns the grammar of chemistry to generate molecules. It treats SMILES strings as a language — each character like C, O, N, (, ), = is like a 'word'. After training on 500,000 real molecules, it learns the patterns and rules, and can then generate entirely new molecules that have never existed before.

The architecture has 3 layers: Embedding layer (converts characters to vectors) → 3 stacked LSTM layers (512 hidden units — this is the 'memory' that learns patterns) → Linear output layer (predicts the next character). It has 5.5 million trainable parameters."

The Toxicity Grader was trained on the Tox21 dataset. If any of the 12 toxicity assays flags a molecule, it's labelled toxic. This grader acts as a safety filter — it prevents poisonous molecules from making it through the pipeline."

❓ Expected Teacher Questions & How To Answer

Q1 "What is the LSTM and why did you choose it?"

Answer: "LSTM (Long Short-Term Memory) is a type of Recurrent Neural Network designed for sequential data. We chose it because SMILES strings are sequences of characters, just like sentences. The LSTM's memory cells can learn long-range dependencies — for example, that an opening bracket '(' in a chemical structure must be closed with ')'. It's a foundational NLP architecture applied to chemistry."

Q2 "How is this different from Agentic AI?"

Answer: "In Agentic AI, the AI agent decides what steps to take autonomously — it plans, uses tools, and adapts its workflow dynamically. In our project, the pipeline flow is hardcoded in pipeline_manager.py. Step 1 always goes to Step 2, which always goes to Step 3. The AI models only make predictions within each step — they never decide the overall workflow. It's more like a factory assembly line than an autonomous robot."

Q3 "What is Prompt Engineering in your project?"

Answer: "In text-based LLMs, prompt engineering means crafting the input text. In our generative model, we use Temperature Scaling as the prompt mechanism. Temperature is a numerical parameter (0.1 to 2.0) that controls the softmax probability distribution during molecule generation. Low temperature makes the AI conservative and repetitive; high temperature makes it creative and diverse. We demonstrated this live with prompt_engineering_demo.py."

Q4 "What is Lipinski's Rule of 5?"

Answer: "It's the pharmaceutical industry's gold standard for drug-likeness. A molecule is considered a viable oral drug if it satisfies: Molecular Weight ≤ 500 Da, LogP ≤ 5 (fat solubility), Hydrogen Bond Donors ≤ 5, and Hydrogen Bond Acceptors ≤ 10. We allow at most 1 violation. About 90% of FDA-approved drugs pass this rule."

Q5 "Where does the data come from? Is it real?"

Answer: "Yes, 100% real. ZINC database (500K molecules from the University of California), ChEMBL (bioactivity data from the European Bioinformatics Institute), PubChem (chemical properties from the US National Library of Medicine), Tox21 (toxicity data from the National Institutes of Health), and RCSB PDB (3D protein structures from the global Protein Data Bank consortium). All fetched live via their public APIs."

Q6 "Why Random Forest and not a Neural Network for grading?"

Answer: "Random Forest is ideal for our use case because: (1) Our training datasets are small (197 molecules for bioactivity, 150 for toxicity) — neural networks need much more data; (2) Random Forest is interpretable — we can see which features matter most; (3) It's fast to train and predict, which matters for a real-time pipeline; (4) It handles the 4 Lipinski features well without needing complex feature engineering."

Q7 "What is the accuracy of your models?"

Answer: "The Bioactivity Grader achieved 77.5% accuracy with a strong F1-score of 0.87 for inactive molecules. The Toxicity Grader achieved ~50-54% accuracy — this is lower because the Tox21 dataset is highly imbalanced (more safe than toxic molecules) and we only used 150 molecules to stay within API rate limits. With the full 8,000 molecules and more compute, this would improve significantly. The pipeline also uses Lipinski Rule of 5 as a rule-based fallback, so even if the ML model is uncertain, the rule-based filter catches bad candidates."

Q8 "What is SMILES notation?"

Answer: "SMILES (Simplified Molecular Input Line Entry System) is a way to represent chemical molecules as text strings. For example, CC(=O)OC1=CC=CC=C1C(=O)O is Aspirin. C = Carbon, O = Oxygen, = means double bond, () means a branch, numbers indicate ring closures. By converting molecules to text, we can apply NLP techniques like sequence generation to chemistry — that's the key insight of our project."

Q9 "Can this actually discover a real drug?"

Answer: "This is a proof-of-concept that demonstrates the AI pipeline architecture. In the real pharmaceutical industry, after our pipeline approves a candidate, it would go through wet lab synthesis, animal trials, and 3 phases of human clinical trials before becoming a real drug. Our project covers the computational first stage — which saves researchers years of manual trial-and-error by narrowing down candidates using AI."

Q10 "What would you improve if you had more time?"

Answer: "Three things: (1) Train the LSTM on a GPU with the full 500K molecules — this would let us generate truly novel molecules instead of using the fallback bank; (2) Build the React frontend so users can interact with the pipeline through a visual dashboard; (3) Use a Transformer architecture (like GPT) instead of LSTM — Transformers are better at learning long-range dependencies in chemical structures, but they need more data and compute."
